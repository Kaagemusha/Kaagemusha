# Antoine Desjonquères

I spent years running consumer businesses where the truth was scattered across disconnected tools and the founder was the integration layer. Now I build the context and controls that let AI agents act on that kind of business safely.

### Two labs, one boundary

- **[Context Layer Lab](https://github.com/Kaagemusha/context-layer-lab)** · [live diagnostic](https://kaagemusha.github.io/context-layer-lab/)

  What does current evidence actually support? Governed records, provenance, validity windows and freshness-aware retrieval, so an agent stops repeating a stale dashboard.

- **[Governed Action Lab](https://github.com/Kaagemusha/governed-action-lab)** · [live console](https://kaagemusha.github.io/governed-action-lab/)

  What may execute, under whose authority, with what receipt? Deterministic policy gates, approvals a model cannot mint, and verifiable action receipts.

Both are small, inspectable reference implementations with deterministic evals and stated limits, not production systems.
